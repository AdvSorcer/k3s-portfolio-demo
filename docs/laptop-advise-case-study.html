k3s GitOps Case Study

Deploying a real Laravel app with Helm, Argo CD, and private GHCR images

Laptop Advise started as an existing production Laravel + Vue/Inertia application. This case study shows how it was connected to a separate infrastructure repository and deployed reproducibly to a k3s cluster.

Application Laravel 12 + Vue/Inertia
Platform k3s + Traefik + PostgreSQL
Delivery GHCR image pinned by commit SHA
URL laptop.panelinker.com

Goal

The goal was not to merge the application source into this repository. The goal was to keep laptop-advise as an independent application repository while using k3s-portfolio-demo as the infrastructure and GitOps repository.

In GitOps terms, the app repo produces an immutable artifact. The infra repo owns the desired state that Argo CD reconciles into the cluster.

Repository Split

laptop-advise

Application repository responsible for Laravel/Vue source code, tests, Docker image builds, and publishing private GHCR images.

  • Builds the app image.
  • Publishes ghcr.io/advsorcer/laptop-advise:<sha>.
  • Does not contain Kubernetes or Argo CD manifests.
k3s-portfolio-demo

Infrastructure repository responsible for the cluster desired state, Helm chart, Argo CD Application, runbooks, and case study.

  • Defines Deployment, Service, Ingress, StatefulSet, and PVC.
  • References the app image by commit SHA.
  • Stores Secret names, not Secret values.

Deployment Flow

1

Developer pushes application code to the app repository.

2

GitHub Actions tests and builds the Laravel container image.

3

The image is pushed to private GHCR with a commit SHA tag.

4

The infra repo pins that image tag in Helm values.

5

Argo CD syncs infra/helm/laptop-advise.

6

k3s pulls the private image and Traefik routes the domain.

ghcr.io/advsorcer/laptop-advise:d5d037594dc014dbb40f1c36ec277a2a5e028e65

Kubernetes Resources

Application

Deployment runs the Laravel container on port 8080. Service exposes it internally on port 80.

Ingress

Traefik routes laptop.panelinker.com to the Laptop Advise service.

Database

PostgreSQL runs as a StatefulSet with a PersistentVolumeClaim for durable data.

Migration

Migrations are documented as a manual command and available as an optional Argo CD PreSync Job.

Security And Secrets

The GHCR package remains private. Kubernetes pulls it through an image pull secret created directly in the cluster. Runtime secrets are also stored in Kubernetes, not Git. 

imagePullSecrets:
  - name: ghcr-pull-secret

laravel:
  secretName: laptop-advise-secret

Private Image Pull

ghcr-pull-secret stores the GitHub token used by k3s to pull the private image from GHCR.

Runtime Secrets

laptop-advise-secret stores Laravel APP_KEY and PostgreSQL password values.

Key Decisions

Separate app and infra repositories

This keeps application code independent while the infrastructure repo remains the source of truth for cluster desired state.

Pin image tags by commit SHA

A fixed tag makes Argo CD diffs and rollbacks clear. The deployment does not depend on mutable latest.

Keep real secrets out of Git

The repository records Secret names and setup instructions, while actual token and password values live in Kubernetes Secrets.

Make migrations explicit

The chart includes an optional PreSync Job, but manual migration remains the default for a small production-like demo.

Validation

kubectl get pods,svc,ingress -n portfolio
curl -I http://laptop.panelinker.com/healthz
curl -I -H 'User-Agent: Mozilla/5.0' http://laptop.panelinker.com

The health endpoint returned 200 OK, the Laravel homepage was reachable through the public domain, and Argo CD reported the Laptop Advise Application as healthy and synced.

Operational Notes

kubectl logs -n portfolio deploy/laptop-advise --tail=120
kubectl exec -n portfolio deploy/laptop-advise -- php artisan migrate --force
  • ImagePullBackOff: check ghcr-pull-secret and GHCR token permissions.
  • CreateContainerConfigError: check laptop-advise-secret has required keys.
  • relation "sessions" does not exist: run Laravel migrations.
  • curl returns 403: the application blocks command-line crawler user agents.

Portfolio Value

This project demonstrates a practical GitOps delivery model for a real Laravel + PostgreSQL workload. The application repository produces the artifact, the infrastructure repository defines the desired state, and Argo CD reconciles the k3s cluster from Git.
